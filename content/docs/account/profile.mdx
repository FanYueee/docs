import { Callout } from 'fumadocs-ui/components/callout';

第一次登入後，系統會帶你到「**我的帳號**」→「**個人設定**」。資料填完才能購買服務。

<Steps>
<Step>
依序填寫姓名、電話與帳單地址。

<Shot src="/images/account/profile-empty.png" alt="個人設定" />
</Step>
<Step>
確認無誤後，按頁面下方的「**儲存資料**」。儲存完成會自動前往[服務商店](/docs/store/start)。
</Step>
</Steps>

<Callout title="儲存後無法自行修改" type="warn">
資料儲存後即鎖定，如需更正請聯絡[客服](/docs/support/tickets)。
</Callout>
