「**商品**」分頁上方是所有產品線，點選後再選地點與方案。

<Shot src="/images/store/catalog.png" alt="商品頁" />

| 產品線 | 說明 |
| --- | --- |
| Minecraft | Minecraft 遊戲主機 |
| 網頁主機 | DirectAdmin 網站主機 |
| Discord 機器人 | 執行 Discord 機器人 |
| 專用伺服器 | 獨立的專用實體伺服器 |
| 附加服務 | 為現有服務加購的項目 |
| Hytale | Hytale 遊戲主機 |
| Steam 遊戲 | Rust、DayZ、ARK |
| 支援等級 | 客服支援等級，見[支援等級](/docs/support/levels) |

</Callout>
