import { Callout } from 'fumadocs-ui/components/callout';
import { Step, Steps } from 'fumadocs-ui/components/steps';

<Callout title="開始之前" type="info">
請先[完成個人資料](/docs/account/profile)。
</Callout>

從選擇方案到建立帳單，只要五個步驟。

<Steps>
<Step>
### 選擇方案

進入「服務商店」→「**商品**」，選好產品線、地點與方案，按「**選擇配置**」。

<Shot src="/images/store/catalog.png" alt="選擇方案" />
</Step>
<Step>
### 配置規格

設定付款週期、端口、備份與資料庫。右側「費用預覽」會即時更新，確認後按「**加入購物車**」。

<Shot src="/images/store/configure-01.png" alt="配置規格" />
</Step>
<Step>
### 加入購物車

可以「繼續選購」其他商品，或「前往購物車」結帳。

<Shot src="/images/store/cart-01.png" alt="已加入購物車" />
</Step>
<Step>
### 確認訂單

檢查商品，有優惠碼請在這裡輸入，再按「**確認下單並建立帳單**」。

<Shot src="/images/store/cart-02.png" alt="確認訂單" />
</Step>
<Step>
### 付款

在帳單明細選擇付款方式並付款，詳見[帳單與付款](/docs/store/billing)。

<Shot src="/images/store/order-01.png" alt="帳單明細" />
</Step>
</Steps>

付款完成後會收到「服務已開通」通知，遊戲主機可到左側的「[遊戲主機](/docs/gamecloud)」管理。
