登入並[完成個人資料](/docs/account/profile)後，從左側選單進入「**服務商店**」。

<Shot src="/images/store/overview.png" alt="服務商店總覽" />

| 分頁 | 用途 |
| --- | --- |
| 總覽 | 待付款、服務狀態與帳務摘要 |
| 商品 | 選購新服務 |
| 我的服務 | 管理已購買的服務 |
| 帳單 | 查看與支付帳單 |
| 通知 | 帳單與服務通知 |

## 新手導覽

第一次進入時，系統會用 5 個步驟帶你操作：

<Steps>
<Step>
選擇產品。

<Shot src="/images/store/tour-01.png" alt="選擇產品" />
</Step>
<Step>
選擇遊戲、地區與方案。

<Shot src="/images/store/tour-02.png" alt="選擇方案" />
</Step>
<Step>
按「選擇配置」，設定後加入購物車。

<Shot src="/images/store/tour-03.png" alt="設定方案" />
</Step>
<Step>
在購物車確認金額並送出訂單，再依帳單付款。

<Shot src="/images/store/tour-04.png" alt="購物車結帳" />
</Step>
<Step>
購買後，在「我的服務」與「帳單」查看狀態。

<Shot src="/images/store/tour-05.png" alt="管理服務與帳單" />
</Step>
</Steps>

完整流程請看[購買服務](/docs/store/buy)。
