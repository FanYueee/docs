import { Callout } from 'fumadocs-ui/components/callout';

在下拉選單「**設定**」→「**伺服器設定**」可以修改伺服器名稱、取得 SFTP 連線資訊，或重新安裝伺服器。

<Steps>
<Step>

### 修改名稱與說明

修改後按「**儲存**」。

<Shot src="/images/gamecloud/settings.png" alt="重新命名" pick={[1]} />
</Step>
<Step>

### 查看連線與除錯資訊

- **SFTP 連線**：位址與使用者名稱，用法見 [SFTP](/docs/gamecloud/sftp)
- **除錯資訊**：節點與伺服器 ID，聯絡客服時請提供

<Shot src="/images/gamecloud/settings.png" alt="SFTP 與除錯資訊" pick={[2, 3]} />
</Step>
<Step>

### 重新安裝伺服器

頁面最下方的「**重新安裝伺服器**」會重新執行安裝腳本，部分檔案可能被刪除或重置。
</Step>
</Steps>

<Callout title="重新安裝前請先備份" type="error">
重新安裝可能刪除或重置部分檔案。請先[建立備份](/docs/gamecloud/backups)。
</Callout>
