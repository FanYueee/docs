[LuckPerms](https://luckperms.net) 是管理權限的插件：決定誰可以使用哪些指令。做法是先建立群組（例如 VIP）、把權限設定在群組上，再把玩家加進群組，比一個一個玩家設定好管理。所有指令都在[主控台](/docs/gamecloud/console)輸入。

<Callout title="先安裝 LuckPerms" type="info">
LuckPerms 是插件，需要 Paper、Purpur 這類插件伺服器。請先到 [LuckPerms 官方網站](https://luckperms.net)下載 .jar 檔，用[手動上傳插件](/docs/gamecloud/plugin-upload)的方式裝好並重新啟動，再開始下面的步驟。
</Callout>

## 常用指令

在主控台輸入時不用加斜線；在遊戲內輸入則要加，例如 `/lp editor`。

| 指令 | 用途 |
| --- | --- |
| `lp creategroup <群組>` | 建立群組 |
| `lp listgroups` | 列出所有群組 |
| `lp group <群組> permission set <權限> true` | 替群組加上權限 |
| `lp group <群組> permission unset <權限>` | 拿掉群組的權限 |
| `lp user <玩家> parent add <群組>` | 把玩家加進群組 |
| `lp user <玩家> parent remove <群組>` | 把玩家移出群組 |
| `lp user <玩家> info` | 查看玩家的群組與資料 |
| `lp editor` | 開啟網頁編輯器 |

## 注意事項

- **玩家必須進來過一次**：LuckPerms 只認得登入過這台伺服器的玩家。玩家還沒進來過時，請他先登入一次，或改用 UUID。
- **大小寫要正確**：玩家名稱、群組名稱與權限節點都要照原樣輸入。
- **權限節點在哪裡找**：每個插件的權限節點都寫在它的說明文件裡，例如 EssentialsX 的 `essentials.home`。官方的[說明文件](https://luckperms.net/wiki/Home)也有完整教學。
- **權限很重要**：給別人權限前請想清楚，尤其是管理員等級的權限。需要的時候可以到[玩家管理](/docs/gamecloud/players)（即將推出）或用 `op` 指令設定管理員。
