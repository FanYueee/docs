SFTP 是加密的檔案傳輸方式，適合上傳或下載大型檔案與資料夾。本篇以 [FileZilla](https://filezilla-project.org) 為例。

<Steps>
<Step>

### 取得連線資訊

進入伺服器的「**設定**」分頁，找到「**SFTP 連線**」，取得位址與使用者名稱。

<Shot src="/images/gamecloud/settings-02.png" alt="SFTP 連線資訊" pick={[1, 2]} />
</Step>
<Step>

### 重設 SFTP 密碼

按「**重設 SFTP 密碼**」取得密碼。

<Callout title="密碼只顯示一次" type="warn">
新密碼只會顯示一次，請立即複製保存。
</Callout>
</Step>
<Step>

### 連線

開啟 FileZilla，依下列格式填寫，再按「**快速連線**」：

```
主機：sftp://<SFTP 位址>
使用者名稱：<SFTP 使用者名稱>
密碼：<重設後取得的密碼>
埠號：<SFTP 連線資訊中的埠號>
```
</Step>
<Step>

### 信任主機金鑰

第一次連線出現「**未知的主機金鑰**」，點選「確定」即可。
</Step>
<Step>

### 開始傳輸

右側顯示檔案結構，代表連線成功，可以直接拖曳檔案上傳或下載。
</Step>
</Steps>
