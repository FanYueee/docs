---
title: 版本安裝
description: 安裝或更換 Minecraft 伺服器類型與版本。
icon: Download
---

import { Callout } from 'fumadocs-ui/components/callout';
import { Step, Steps } from 'fumadocs-ui/components/steps';

在「軟體 → 版本安裝」可以安裝或更換伺服器類型與 Minecraft 版本，例如官方原版、Paper、Purpur、Forge、Fabric。世界、外掛和設定檔都會保留。

</Step>
<Step>

<Shot src="/images/tutorials/versions/02.webp" alt="安裝或更換 Minecraft 版本 步驟 2：選「版本安裝」" width={2800} height={1800} caption="選「版本安裝」。" />
</Step>
<Step>

<Shot src="/images/tutorials/versions/03.webp" alt="安裝或更換 Minecraft 版本 步驟 3：先選伺服器類型" width={2800} height={1800} caption="先選伺服器類型。上方可以用分類篩選：官方原版、插件伺服器（Paper、Purpur…）、模組伺服器（Forge、Fabric…）。要裝外掛選插件伺服器，要裝模組選模組伺服器。" />

<Step>

<Shot src="/images/tutorials/versions/04.webp" alt="安裝或更換 Minecraft 版本 步驟 4：這裡以最常用的 Paper 為例，點「Paper」" width={2800} height={1800} caption="這裡以最常用的 Paper 為例，點「Paper」。" />
</Step>

<Shot src="/images/tutorials/versions/05.webp" alt="安裝或更換 Minecraft 版本 步驟 5：選擇 Minecraft 版本" width={2800} height={1800} caption="選擇 Minecraft 版本。最上面是最新版；要和朋友的遊戲版本一致就選相同版本，這裡選 1.21.4。" />
</Step>
<Step>

<Shot src="/images/tutorials/versions/06.webp" alt="安裝或更換 Minecraft 版本 步驟 6：「Build」預設是最新的穩定版，一般不用改" width={2800} height={1800} caption="「Build」預設是最新的穩定版，一般不用改。下方「安裝資訊」會列出要下載的檔案、會換成哪個 Java 版本，以及舊的啟動檔會被移到隔離資料夾（不會刪除）。" />
</Step>
<Step>

<Shot src="/images/tutorials/versions/07.webp" alt="安裝或更換 Minecraft 版本 步驟 7：確認無誤後按右下角「開始安裝」" width={2800} height={1800} caption="確認無誤後按右下角「開始安裝」。" />

</Step>
<Step>

<Shot src="/images/tutorials/versions/10.webp" alt="安裝或更換 Minecraft 版本 步驟 10：看到「版本檔案已安裝」、每個步驟都打勾就完成了" width={2800} height={1800} caption="看到「版本檔案已安裝」、每個步驟都打勾就完成了。按「前往主控台啟動」並啟動伺服器，新版本就會開始執行。" />
