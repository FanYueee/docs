## 更換遊戲版本

在「Server Version」填入版本號，`latest` 為最新正式版，`snapshot` 為最新快照。

<Callout title="需要重新安裝才會生效" type="warn">
儲存後，請到「[設定](/docs/gamecloud/settings)」按「重新安裝伺服器」。請先[建立備份](/docs/gamecloud/backups)。
</Callout>

遊戲版本不同需要的 Java 版本也不同，啟動失敗時請檢查「執行環境」。
