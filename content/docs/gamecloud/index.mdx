---
title: 遊戲主機總覽
description: 在「遊戲主機」管理你的遊戲伺服器。
icon: Gamepad2
---

import { Callout } from 'fumadocs-ui/components/callout';

登入 [portal.vproxy.cloud](https://portal.vproxy.cloud)，從左側選單進入「**遊戲主機**」，點選伺服器即可管理。

<Shot src="/images/gamecloud/list.png" alt="遊戲主機列表" />

| 分頁 | 用途 |
| --- | --- |
| [主控台](/docs/gamecloud/console) | 開關機、輸入指令、查看日誌 |
| [檔案](/docs/gamecloud/files) | 上傳、編輯、下載檔案 |
| [資料庫](/docs/gamecloud/databases) | 資料庫額度 |
| [排程](/docs/gamecloud/schedules) | 自動執行任務 |
| [使用者](/docs/gamecloud/users) | 邀請朋友共同管理 |
| [備份](/docs/gamecloud/backups) | 建立與還原備份 |
| [網路](/docs/gamecloud/network) | 內網名稱與流量 |
| [啟動設定](/docs/gamecloud/startup) | 啟動指令、Java 與遊戲版本 |
| [設定](/docs/gamecloud/settings) | 重新命名、SFTP、重新安裝 |
| [分析](/docs/gamecloud/analytics) | 資源使用歷史 |
| [告警](/docs/gamecloud/alerts) | 資源過高時通知你 |
| [操作紀錄](/docs/gamecloud/activity) | 操作歷史 |

<Callout title="第一次啟動需要等待" type="info">
第一次啟動需要下載遊戲檔案，請等候幾分鐘。
</Callout>
