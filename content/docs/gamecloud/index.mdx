「遊戲主機」是你購買的遊戲伺服器的管理介面，可以開關機、上傳檔案、建立備份、邀請朋友一起管理。

<Steps>
<Step>

### 進入遊戲主機

登入 [portal.vproxy.cloud](https://portal.vproxy.cloud)，從左側選單進入「**遊戲主機**」，點選要管理的伺服器。

<Shot src="/images/gamecloud/list.png" alt="遊戲主機列表" />
</Step>
<Step>

### 使用功能

進入伺服器後，上方是功能分頁，點選即可切換。「軟體」「遊戲」「網路」「紀錄」「設定」是下拉選單。

| 功能 | 位置 | 用途 |
| --- | --- | --- |
| [主控台](/docs/gamecloud/console) | 主控台 | 開關機、輸入指令、查看日誌 |
| [檔案](/docs/gamecloud/files) | 檔案 | 上傳、編輯、下載檔案 |
| [版本安裝](/docs/gamecloud/versions) | 軟體 → 版本安裝 | 安裝或更換 Minecraft 版本 |
| [模組包](/docs/gamecloud/modpacks) | 軟體 → 模組包 | 一鍵安裝模組包 |
| [單一外掛](/docs/gamecloud/plugins) | 軟體 → 單一外掛 | 搜尋並安裝外掛或模組 |
| [世界上傳與下載](/docs/gamecloud/worlds) | 遊戲 → 地圖 | 上傳、下載與還原世界 |
| [玩家管理](/docs/gamecloud/players) | 遊戲 → 玩家管理 | 白名單、管理員與封鎖 |
| [備份](/docs/gamecloud/backups) | 備份 | 建立與還原備份 |
| [排程](/docs/gamecloud/schedules) | 排程 | 自動執行任務 |
| [網路](/docs/gamecloud/network) | 網路 → 網路 | 連線位址與流量 |
| [資料庫](/docs/gamecloud/databases) | 網路 → 資料庫 | 資料庫額度 |
| [使用者](/docs/gamecloud/users) | 使用者 | 邀請朋友共同管理 |
| [分析](/docs/gamecloud/analytics) | 紀錄 → 分析 | 資源使用歷史 |
| [告警](/docs/gamecloud/alerts) | 紀錄 → 告警 | 當機與資源過高時通知你 |
| [操作紀錄](/docs/gamecloud/activity) | 紀錄 → 操作紀錄 | 操作歷史 |
| [啟動設定](/docs/gamecloud/startup) | 設定 → 啟動設定 | 啟動指令、Java 與遊戲版本 |
| [伺服器設定](/docs/gamecloud/settings) | 設定 → 伺服器設定 | 重新命名、SFTP、重新安裝 |
| [SFTP](/docs/gamecloud/sftp) | 設定 → 伺服器設定 | 傳輸大型檔案與資料夾 |
</Step>
<Step>

### 展開下拉選單

點選「網路」「紀錄」「設定」，會展開裡面的功能。

<Shot src="/images/gamecloud/menu-network.png" alt="網路下拉選單" />

<Shot src="/images/gamecloud/menu-records.png" alt="紀錄下拉選單" />

<Shot src="/images/gamecloud/menu-settings.png" alt="設定下拉選單" />
</Step>
</Steps>

<Callout title="第一次啟動需要等待" type="info">
第一次啟動需要下載遊戲檔案，請等候幾分鐘。
</Callout>
