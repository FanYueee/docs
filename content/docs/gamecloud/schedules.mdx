排程可以讓伺服器在固定時間自動執行任務，例如每天凌晨重新啟動、定時公告。

<Callout title="時間以台北時間為準" type="info">
排程時間使用「**台北標準時間（UTC+8）**」。
</Callout>

<Steps>
<Step>

### 新增排程

按「**新增排程**」，填寫名稱、頻率與時間，再按「**儲存**」。

<Shot src="/images/gamecloud/schedules-new.png" alt="新增排程" />
</Step>
<Step>

### 新增任務

建立好的排程會列在頁面上，可以用左側開關啟用或停用。在排程下方按「**新增任務**」。

<Shot src="/images/gamecloud/schedules-list.png" alt="排程列表" />
</Step>
<Step>

### 設定任務內容

選擇動作（預設為「傳送指令」），填寫內容；「**延遲時間**」是與上一個任務間隔幾秒，「**失敗時仍繼續後續任務**」決定上一步出錯時要不要繼續。完成後按「**儲存**」。一個排程可以有多個任務，會依序執行。

<Shot src="/images/gamecloud/schedules-task.png" alt="新增任務" />

例如先公告，60 秒後再重新啟動：任務 1 選「傳送指令」，內容填：

```
say 伺服器將在 1 分鐘後自動重啟，請先下線
```

任務 2 選「電源動作」，延遲 60 秒，內容填：

```
restart
```
</Step>
</Steps>

排程可以「**立即執行**」、編輯或刪除。
