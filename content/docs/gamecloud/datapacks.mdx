import { Callout } from 'fumadocs-ui/components/callout';

在「軟體 → 資料包」可以安裝與移除資料包。系統會自動放到正確的位置，不需要自己找資料夾。基岩版伺服器這裡會顯示「附加包」。

<Callout title="什麼時候生效" type="info">
伺服器關機時，下次啟動會自動載入資料包。伺服器正在運作時，安裝完成後會多一個「執行 /minecraft:reload」按鈕，按一下就能立即生效，不用重開。
</Callout>
