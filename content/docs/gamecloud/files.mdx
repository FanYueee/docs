---
title: 檔案

---

import { Callout } from 'fumadocs-ui/components/callout';
import { Step, Steps } from 'fumadocs-ui/components/steps';

在「檔案」可以瀏覽伺服器內的檔案，直接在網頁上上傳、編輯、壓縮、移動或刪除。

{/* tutorial:start */}

<Step>

</Step>
<Step>

<Shot src="/images/tutorials/files/02.webp" alt="檔案管理 步驟 2：按「新增資料夾」建立新的資料夾" width={2800} height={1800} caption="按「新增資料夾」建立新的資料夾。" />
</Step>
<Step>

<Shot src="/images/tutorials/files/03.webp" alt="檔案管理 步驟 3：輸入資料夾名稱，按「建立」" width={2800} height={1800} caption="輸入資料夾名稱，按「建立」。" />
</Step>
<Step>

<Shot src="/images/tutorials/files/04.webp" alt="檔案管理 步驟 4：要從電腦上傳檔案，按「上傳」選擇檔案；也可以直接把檔案拖曳到列表上" width={2800} height={1800} caption="要從電腦上傳檔案，按「上傳」選擇檔案；也可以直接把檔案拖曳到列表上。整個資料夾請用「上傳資料夾」。" />
</Step>
<Step>

<Shot src="/images/tutorials/files/05.webp" alt="檔案管理 步驟 5：上傳完成後檔案會出現在列表中" width={2800} height={1800} caption="上傳完成後檔案會出現在列表中。" />
</Step>
<Step>

<Shot src="/images/tutorials/files/06.webp" alt="檔案管理 步驟 6：檔案在網路上（例如外掛或地圖的下載連結）時，可以按「從網址下載」，讓伺服器直接下載，不用先存到電腦" width={2800} height={1800} caption="檔案在網路上（例如外掛或地圖的下載連結）時，可以按「從網址下載」，讓伺服器直接下載，不用先存到電腦。" />
</Step>
<Step>

<Shot src="/images/tutorials/files/07.webp" alt="檔案管理 步驟 7：貼上直接下載的網址，按下載後進度會顯示在右下角" width={2800} height={1800} caption="貼上直接下載的網址，按下載後進度會顯示在右下角。這裡示範先按「取消」。" />
</Step>
<Step>

<Shot src="/images/tutorials/files/08.webp" alt="檔案管理 步驟 8：點檔案名稱可以直接在網頁上編輯，例如 server.properties" width={2800} height={1800} caption="點檔案名稱可以直接在網頁上編輯，例如 server.properties。" />
</Step>
<Step>

<Shot src="/images/tutorials/files/09.webp" alt="檔案管理 步驟 9：修改內容後按「儲存」，按「關閉」回到檔案列表" width={2800} height={1800} caption="修改內容後按「儲存」，按「關閉」回到檔案列表。設定檔改完通常要重新啟動伺服器才會生效。" />
</Step>
<Step>

<Shot src="/images/tutorials/files/10.webp" alt="檔案管理 步驟 10：勾選多個檔案或資料夾後，上方會出現批次操作：壓縮、移動或刪除" width={2800} height={1800} caption="勾選多個檔案或資料夾後，上方會出現批次操作：壓縮、移動或刪除。這裡勾選三個世界資料夾後按「壓縮所選」。" />
</Step>
<Step>

<Shot src="/images/tutorials/files/11.webp" alt="檔案管理 步驟 11：壓縮完成會產生 .tar.gz 檔" width={2800} height={1800} caption="壓縮完成會產生 .tar.gz 檔。檔案右側可以下載、重新命名，「⋯」裡還有複製、移動、權限、解壓縮與刪除。" />
</Step>
<Step>

<Shot src="/images/tutorials/files/12.webp" alt="檔案管理 步驟 12：選「解壓縮」就能把壓縮檔解開到目前的資料夾" width={2800} height={1800} caption="選「解壓縮」就能把壓縮檔解開到目前的資料夾。" />
</Step>
</Steps>
{/* tutorial:end */}

<Callout title="設定需要重新啟動" type="info">
`server.properties` 等設定檔修改後，請到[主控台](/docs/gamecloud/console)重新啟動才會生效。
</Callout>

大型檔案或整個資料夾，建議使用 [SFTP](/docs/gamecloud/sftp)。
