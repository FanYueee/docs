import { Callout } from 'fumadocs-ui/components/callout';

在「檔案 → 從其他主機搬家」可以透過 SFTP，把舊主機上的檔案直接搬到這台伺服器，不需要先下載到電腦再上傳。

<Callout title="舊主機不會被動到" type="info">
我們只會讀取舊主機的檔案，不會改動或刪除。搬過來時被換掉的檔案，也會先移到備份資料夾，不會刪除。
</Callout>

搬家前，請先在舊主機找到「SFTP 詳細資料」：主機位址、連接埠、使用者名稱與密碼。
