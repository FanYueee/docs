---
title: 建立新世界
description: 換一個全新的世界，或只重置地獄、終界，原本的世界會先保存。

unlisted: true

import { Callout } from 'fumadocs-ui/components/callout';
import { Step, Steps } from 'fumadocs-ui/components/steps';

在「遊戲 → 地圖 → 建立新世界」可以換一個全新的世界，或只重置地獄、終界。

<Callout title="原本的世界不會被刪除" type="info">
換世界前，目前的世界會先保存到備份資料夾，之後隨時可以在「還原成上一個世界」換回來。
</Callout>

<Callout title="只重置地獄或終界" type="info">
主世界、玩家的物品與進度都不會變，只有地獄或終界會重新產生。
</Callout>
