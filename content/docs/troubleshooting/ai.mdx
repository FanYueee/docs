import { Step, Steps } from 'fumadocs-ui/components/steps';
import { Callout } from 'fumadocs-ui/components/callout';

AI 工具如 ChatGPT 可以協助您快速診斷和解決各種技術問題。正確使用 AI 可以大幅提升問題解決的效率，特別是在遇到複雜的伺服器設定或錯誤訊息時。

至撰寫此文檔時，[ChatGPT](https://chat.openai.com/) 與 [Gemini](https://gemini.google.com/app) 兩個可以提供免費 AI 工具提供一定能力的技術支援。這些工具能夠理解您的問題並提供解決方案。

本篇以 ChatGPT 為例，介紹如何使用 AI 協助解決伺服器問題。

<Steps>
<Step>
### 註冊 ChatGPT 帳戶
前往 [ChatGPT 官網](https://chat.openai.com/) 註冊或登入帳戶，並進入對話介面。
![ChatGPT 對話介面](/images/troubleshooting/ai/1.png)
</Step>

<Step>
### 要求繁體中文支援
在對話中輸入以下指令，讓 AI 使用繁體中文回答問題：
```
請使用繁體中文回答我的問題
```
![要求 AI 使用繁體中文回答](/images/troubleshooting/ai/2.png)
</Step>

<Step>
### 描述您的問題
將伺服器控制台的錯誤完整進行複製貼上，並可加上一些問題描述，例如：「分析我的 Minecraft 伺服器錯誤」

```
分析我的 Minecraft 伺服器錯誤：
[GameCloud]: 正在準備伺服器儲存空間...
[GameCloud]: 正在套用執行環境設定...
[GameCloud]: 正在檢查工作目錄權限...
[GameCloud]: 正在更新伺服器執行環境...
[GameCloud]: 伺服器執行環境已就緒。
container~ java -version
openjdk version "21.0.13" 2026-10-20 LTS
OpenJDK Runtime Environment Temurin-21.0.13+9 (build 21.0.13+9-LTS)
OpenJDK 64-Bit Server VM Temurin-21.0.13+9 (build 21.0.13+9-LTS, mixed mode, sharing)
container~ java -Xms128M -XX:MaxRAMPercentage=95.0 -Dterminal.jline=false -Dterminal.ansi=true -jar ${SERVER_JARFILE}
Error: Unable to access jarfile server.jar
```
![主控台的錯誤訊息，已選取要複製的內容](/images/troubleshooting/ai/3.webp)
</Step>

<Step>
### 了解 AI 回答
AI 會分析錯誤訊息並提供可能的解決方案或總結。您將可以依照 AI 的建議進行操作。
![AI 回答範例](/images/troubleshooting/ai/4.webp)

<Callout type="info">
    回答內容僅為範例，實際內容會依 AI 工具而不同。
</Callout>
</Step>
</Steps>
